# Interface translations

The default interface is Chinese; the header selector switches to English immediately. No network translation service is used.

- `src/i18n.js` owns locale preference, interpolation, validation-message translation and DOM updates.
- `src/locales/en.json` maps Chinese source messages to English. Chinese source strings act as gettext-style keys.
- Static HTML uses `data-i18n`, or `data-i18n-aria-label` / `data-i18n-placeholder` / `data-i18n-content` for attributes. Translate text leaves, preserving inputs and event handlers.
- Dynamic UI calls `t(message, {parameters})`. Escape text before inserting HTML. Keep user filenames, region names, item registry IDs and block-state properties intact.
- Geometry, operation IDs and the planner's canonical data do not depend on the locale. Locale changes update display text without recalculating the build plan or changing progress.
- Browser preference is stored separately from schematic progress. Project JSON and exported offline HTML include their selected locale. Older project files remain readable.

Use `npm test` for interpolation and catalog coverage, and `npm run test:e2e` for switching, current-group/view restoration, custom names, offline English HTML, print output and narrow layouts.
