# 使用说明

## 导入与定位

1. 点击「导入图纸」，选择 Sponge `.schem v3` 文件。也可先体验原创示例。
2. 在「地面与游戏坐标」确认地面。模型中点击路面方块，再点击「用所选方块设定地面基准」，可以同时设置原图 X/Y/Z。
3. 填入该地面方块在游戏中的 X/Y/Z。若读取站立时 F3 的脚部 Y，减 1 后填写。地面下部分应位于地下，不要把河底/地下室当作游戏地面。
4. 图纸 Offset 会保留；界面显示从0开始的局部坐标，不会擅自套用原作者的世界位置。

## 调整施工内容

默认按最多3层合并主体，再安排细节。可以改为逐层或其他高度，并勾选「地下部分后建」。

在俯视图拖动框选，输入部位名称，点击「新建分区」。也可直接填写包括首尾的 X/Y/Z 范围。后创建的分区拥有重叠的源方块；其他源方块自动留在「未划分部分」。

用分区的 ↑/↓ 改变部位施工顺序；「并入上区」保留两区完整范围。操作按稳定的源坐标记录，重新分组保留已完成状态。门、床不会因为框选边界被拆为两次放置。

## 跟建与材料

整段视图适合看结构，逐组视图适合数连续矩形或墙面。格数是实际占用范围，空位不填。石砖/苔石砖可在同一施工组，但每格材质不变。

实体表示已确认，金边半透明表示当前目标，虚影是尚未确认的定位参考。预演不改变进度。实际建好后点击登记；「撤回」只改网页记录，不会改游戏世界。

材料按尚未完成的操作统计；CSV为完整图纸清单。普通物品组数以64为显示单位，特殊物品的游戏堆叠上限仍须在游戏内核对。液体、模组方块和特殊构件有提示，清单以创造模式教学为主。

## 原始材质

点击「导入原版材质」，选择本机 Java 客户端 `.jar` 或 `.zip` 资源包。文件仅在本地处理。资源缺失时仍显示原方块ID并保留示意外形；部分内置动态模型有简化。

资源包通常不包含默认基础模型，此时优先导入完整客户端资源。首版尚不叠加多档案资源优先级。

## 保存、携带与打印

- **本机进度**：浏览器保存进度；重新导入完全相同的图纸文件会恢复设置与记录。清理浏览器数据会删除本机记录。
- **保存项目**：导出包含图纸、设置、素材和进度的 JSON，以后用「打开项目」恢复。
- **导出离线网页**：得到单个 HTML，复制到其他电脑用 Chrome/Edge 打开，含当前图纸、资源和进度，不需要服务器。
- **打印**：页头「打印」或 Ctrl+P，生成当前施工目标、格数、地面基准与材料表。建议先选好施工段、视角与剖切高度。

无WebGL时自动使用二维备用模型，数格、材料、进度和打印仍可用，但不是透视3D。大图首次分组和备用绘图可能较慢，可取消计算后缩小图纸。

## 中文 / English

页头语言选择器可即时切换中文和英文。界面、施工说明、材料名称、错误提示、打印及CSV会同步切换；自定义图纸和分区名称保持原样。浏览器会记住选择，也可使用 `?lang=en` 打开英文工具。

保存项目或导出离线HTML会包含所选语言，以及当前施工组、剖切高度和视角。打开项目时先完整验证，格式无效或计算失败不会替换当前图纸和进度。
